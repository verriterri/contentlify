Clear Supabase Session & Cookies

Use this tool to clear all Supabase-related cookies and session data from your browser. This is useful when switching to a new database.

Steps to Switch to New Database:

  1. Update your .env.local file with new database credentials:
    • NEXT_PUBLIC_SUPABASE_URL - Your new project URL
    • NEXT_PUBLIC_SUPABASE_ANON_KEY - Your new anon key
    • SUPABASE_SERVICE_ROLE_KEY - Your new service role key
  2. Click the button above to clear old cookies
  3. Restart your Next.js development server (stop with Ctrl+C, then run npm run dev again)
  4. Clear browser cache (optional but recommended: Cmd+Shift+R on Mac, Ctrl+Shift+R on Windows)
  5. Try logging in again with your new database credentials
